# 📂 Sample Datasets for Testing & Quality Profiling

This directory contains sample tabular datasets (`.csv`, `.xlsx`, `.json`) for testing and demonstrating **DataCleanAI**'s automated profiling, machine learning cleaning pipelines, and DuckDB SQL console features.

---

### 📁 Uploading Sample Files

Place your test datasets directly into this directory:

- `enterprise_customer_leads.csv`
- `crime_incidents.csv`
- `financial_transactions.csv`
- `healthcare_patient_records.json`
- `ecommerce_sales.xlsx`

Once placed here, you can commit and push them to GitHub or drag-and-drop them into the DataCleanAI web application uploader!
